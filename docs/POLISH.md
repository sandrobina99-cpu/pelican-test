# 打磨清单

统一打磨时再改。这一份只记账，现在不要动手。

- 唐代白描里的屏风看起来像一台电脑显示器。改成折屏或立屏的线描，不要画成矩形加支架。
- 八大山人的石头是一块硬边黑多边形，不像一笔湿墨。改成有飞白和浓淡的墨块。
- 莫卧儿细密画的花坛读成十字铺地砖。改成从上方看的花圃：花、叶、几何边，不要四格十字。
- 浮世绘太平。海浪要接近北斋那种层叠的弧线浪，再加更密的松针和岸上的细节。
- 清明上河图仍然偏小、偏淡，密度还没到原画那种拥挤。人物、船、屋顶都要再大一号、再深一号。
- 星月夜的鹈鹕太暗，融进夜空。要更大的梵高式旋涡，柏树也要更明确；鹈鹕用亮色短笔触从天上分离出来。
- 呐喊里的鹈鹕塌成一个白圈，剪影没了。身体、脖子、喙要重新连成一只能认出的鸟。
- 诺斯费拉图的影子现在是一辆车加一个三角，不像鹈鹕的影子。整格改成高反差的暗色表现主义，不要平的灰条纹。
