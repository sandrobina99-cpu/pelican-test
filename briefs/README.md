# 美术简报

17 个还没画的版块，简报在 `sNN-*.md`。不要照搬任何现成作品的构图。

## 批次

1. **水墨（这一批）**：3 汉画像石、4 唐代白描、6 清明上河图、9 八大山人。同一批把 5 宋代山水从平涂改成皴法、晕染、雾气和纸纹，鹈鹕改成墨线。
2. **平涂与细密**：2 埃及壁画、7 玛雅抄本、8 莫卧儿细密画、11 浮世绘。
3. **近代画与早期影像**：12 星月夜、13 呐喊、14 诺斯费拉图、15 示波器。14 进 15 的那一拍，影子通电变成绿线。
4. **晚近媒介**：10 皮影、16 8-bit、17 聊天窗、18 蒸汽波、20 代码美学。8-bit 的中文用 Pelican Pixel（Fusion Pixel 的子集），拉丁像素字可以用 Press Start 2P。

每一格仍是 6 秒：0–2 秒进场，2–4 秒是梗，4–6 秒骑向下一个画框。姿势继续用同一套骨骼。
